# 千问十维非思考格点

[English](README.md)

| 项目 | 配置 |
|---|---|
| 维度 | O开放；C尽责；E外向；A宜人；N神经质；R风险承担；T未来后果；V亲社会分配；M物质价值；S感官敏感 |
| 每维系数 | `{-1,0,1}` |
| 从0开始的层索引 | `40,32,32,16,32,32,40,32,40,32` |
| 分数 | 问卷与行为分数等权平均，0–100 |
| 注入 | 全部有效输入与生成token |
| 筛选 | 每维／接口合法答案概率≥.98；问卷映射差≤25；行为换序差≤.25；原始A/B偏置≤.90 |

`measurements.npz` 保存59,049个节点；`node_gate_metrics.npz` 保存筛选依据；`catalog.json` 提供33,942个合格节点；`vectors.npz` 为按上述顺序排列的十根FP32向量。

维度代码 S 指感官敏感；`scores` 指问卷／行为综合分。分开分析时使用 `questionnaire_scores` 和 `behavior_scores`。
